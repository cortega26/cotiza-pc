## Considered and rejected or deliberately deferred

- **Hosted public quote sharing and automated price feeds**: explicitly deferred by the existing product registry; both require backend/data/commercial decisions beyond current scope.
- **Standalone catalog-confidence UI project**: not separately planned. Evidence/provenance behavior required for current correctness is embedded in Plans 014, 017-019, and the direction designs.
- **Professional/store CRM, branded exports, inventory integration**: deliberately long-term in the canonical vision; defer until the consumer decision engine is credible.
- **Blanket dependency upgrades, Prettier, pre-commit framework, search dependency, or virtualization**: no measured defect or security advisory justifies them. Plan 023 permits only measured, dependency-free optimization first.
- **Immediate deletion of `App.css`, React scaffold assets, `memory.min.json`, or unused `socketSet`**: cleanup value is too low or external artifact compatibility is uncertain; review opportunistically inside an owning future change.
- **Formal WCAG/accessibility overhaul**: not covered by the deep audit playbook and therefore not claimed as audited. Run the dedicated accessibility skill/audit separately before treating accessibility as complete.
