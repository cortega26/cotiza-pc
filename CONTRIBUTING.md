# PC Quote Builder — Contributor Guide

## Product vision

Before making material changes to recommendations, compatibility, core flows, scoring, warning/unknown/failure semantics, rankings, monetization, or constraining architecture, read [the Canonical Product Vision](docs/PRODUCT_VISION.md). It is the highest-authority product source of truth.

## Quick start

```sh
cd pc-quote-builder
npm ci
npm run check      # lint + test + disposable build
npm run dev        # Vite dev server (hot-reload)
```

## Development commands

All commands run from `pc-quote-builder/` unless noted.

| Command | Purpose |
|---|---|
| `npm run dev` | Vite dev server with hot reload |
| `npm run lint` | ESLint (flat config) |
| `npm test` | Vitest suite (jsdom) |
| `npm run check` | **Required gate** — lint + test + disposable build |
| `npm run build` | Production build → `../docs/` (GitHub Pages) |
| `npm run build:check` | Build to `/tmp/pc-check-build` (disposable, non-mutating) |

## Catalog data pipeline

Generated artifacts — never hand-edit.

```sh
npm run pc-data:all          # full pipeline: download → build → sync

# Individual steps:
pip install --require-hashes -r ../scripts/requirements.txt   # Python deps (once)
npm run download:pc-data    # download raw datasets
npm run build:pc-data       # normalize → data/processed/
npm run sync:pc-data        # copy → public/data/
npm run test:artifacts      # validate artifact contracts (pre-build)
```

A scheduled workflow (`.github/workflows/pc-data-cron.yml`) runs the pipeline every 14 days and deploys to GitHub Pages.

## Generated artifacts — do not hand-edit

| Path | Status |
|---|---|
| `data/processed/` | Generated by `build:pc-data` |
| `pc-quote-builder/public/data/` | Synced from processed via `sync:pc-data` |
| `docs/` | Vite production build output |

The canonical product document at `docs/PRODUCT_VISION.md` is source documentation, not a generated artifact.

## Testing

- Co-located with source as `*.test.js` / `*.test.jsx`
- Vitest with jsdom environment
- Testing Library (`fireEvent`, `waitFor`, `screen`)
- Include sad paths: null/empty inputs, failed loads, cancellation
- Run `npm run test:artifacts` after catalog data changes
- Run `npm run check` before any commit
